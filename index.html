📋 1. Project Title & Description

▼

Project Title: Data Analytics Job Entry

Apply to at least one Data Analytics position using compiled material that showcases my skills/projects in an easy-to-navigate way while also being visually interesting.

🎯 2. Vision, Mission & Strategy Alignment

▼

Personal Mission Connection:

My mission is to gain more experience, gain more valuable skills in data analytics, and to actually enjoy the work that I do. This project supports my personal mission by providing a base platform where I can continue to add new skills and projects I will accumulate over time. It provides me with a tangible incentive so I can stay motivated in becoming more skilled in Data Analytics.

Vision Alignment:

My vision is to have a data analytics position in a company whose values I align with, and to be recognized for providing valuable analysis that brings improvement to the business. This portfolio will greatly help me find entry in my preferred job market, which is Data Analytics. This portfolio will allow me to confidently submit and pursue positions in data analytics that I would previously not be able to confidently do.

Strategic Goal Support:

This will help me accomplish my strategic goal of using the portfolio to apply to at least one Data Analytics internship/position by the end of the semester. Having a collection of all my projects/skills (or overall achievements) that I can easily submit will make showcasing myself to businesses that are hiring more efficient.

💼 3. Business Case & Justification

▼

Professional Value:

This project will help me pursue my preferred career as it will be a collection of all my skills, projects, and achievements.

Personal Value:

This project provides me with a tangible incentive to continue improving and adding to. It allows me to organize and evaluate all my skills and projects that I have accumulated so far.

Learning Outcomes:

I believe the main takeaway I will get from this project is project management skills. I have never really worked on a long-term project before, and it makes me aware of aspects of managing a project I never thought of before.

🔍 4. High-Level Scope

▼

✅ In Scope for Semester Project

  • A responsive website with a clean, professional design
  • A home page with an introduction and summary about me
  • A portfolio section showing 2 data analytics projects with visuals and short explanations
  • A resume page with a downloadable PDF option
  • A contact form for messages
  • A section showing relevant certifications (Google Data Analytics)

🗺️ Roadmap Items (≤6 Months)

  • Interactive dashboards using Tableau, Power BI, or Python
  • Links to LinkedIn and GitHub for automatic updates
  • Updates/new project additions
  • A custom domain name

❌ Out of Scope

  • Build a big company-level data system
  • Set up automatic data pipelines that refresh by themselves
  • Add advanced AI features (like chatbots or recommendations)
  • Create a mobile app version of the portfolio
  • Support multiple languages

⚙️ 6. Project Methodology

▼

Explanation:

My requirements are well-defined and unlikely to change → Predictive

For my project, predictive is a good methodology as it is straightforward and works with my schedule throughout the semester. It defines a start and an end which allows me to stay on task, and lets me comfortably build my portfolio piece by piece.

🛠️ 7. Project Tool Selection

▼

Explanation:

I chose Microsoft Project (Planner)

I chose Microsoft Project (Planner) as my tool for this project because it is well-suited for predictive project management. My project has a fixed end date at the end of the semester, and Microsoft Project allows me to create a detailed schedule with clear dependencies, milestones, and deadlines. Its calendar functionality helps visualize the timeline, ensuring tasks are completed in sequence and on time. This level of structure and control supports the predictive methodology's focus on upfront planning and minimizing risks.
